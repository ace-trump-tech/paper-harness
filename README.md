## 🧭 它是什么？

**Paper Harness** 不是“输入题目 → 吐出论文”的魔术黑盒。  
它是面向整个科研生命周期的**研究编排框架**——你可以把它看作一个“研究操作系统”：

- **多 Agent 协作**：文献、创新组合、实验执行、论文写作各司其职；
- **证据驱动**：每个结论都绑定来源（文献页码、运行日志、人工审批）；
- **可中断 / 可恢复**：长周期实验可随时暂停，恢复后继续；
- **人工始终在环**：关键决策点（方案选择、实验批准、论文 claim）必须由你确认。

它的核心工作流是一条清晰的主线：

> **题目 / 已有代码** → 文献与本地知识库 → 假设和创新组合 → 实验 / 仿真 / 代码任务 → 指标与失败分析 → 论文初稿和研究仓库 → 相似度、AI 使用、claim 和许可证审查 → **你确认后发布**

---

## ⚙️ 原理：合同驱动，不留模糊地带

Harness 的每一阶段都通过明确定义的“合约”约束：

- 输入（必须有什么）
- 输出（必须产出什么）
- 完成定义（什么算“做完”）
- 审批要求（需要你确认什么）

所有运行产物都会生成 **SHA-256 清单**，外部修改文件会立即被检测到。  
每个实验强制保存：配置、随机种子、数据版本、原始日志、指标、失败信息——**可复现不是口号，是默认行为**。

## 🛡️ 研究边界与合规声明

- **不伪造指标**：未配置数据集、代码仓和 runtime 时，系统不会凭空生成实验数据。
- **权威来源不可绕过**：专业版的电网/控制任务，只认仿真器、数值求解器和安全门控的输出；LLM 只能提出方案、调用工具和解释结果，不能直接控制设备。
- **论文不自动投稿**：最终引用、图表、许可证、Claim 必须经你人工确认。
- **组合候选不自动成立**：必须做消融、基线对比和统计核验，通过后才会进入下一轮。
- 不绕过登录、付费墙、验证码或数据库规则；所需资料请由你**合规导入**。
- 相似度检查为本地初步筛查，**不替代学校正式查重系统**。
- AI 使用披露模块仅提示规范，**不提供规避 AI 检测的功能**。
